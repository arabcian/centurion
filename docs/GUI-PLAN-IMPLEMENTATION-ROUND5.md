# Centurion Experimental — Beşinci geliştirme turu / kümülatif devir raporu

Temel: `Centurion-experimental-gelistirme-tur4.zip`. A01–D05 planındaki son dört hiç başlanmamış pakete yönelik kısmi uygulama eklendi. Bütün paketlerde en az bir uygulama bulunuyor (D05 doğrulama engelli); bu, planın tamamlandığı veya kabul kriterlerinin geçtiği anlamına gelmez.

## Bu turda değişiklikler

- A02: Tema token storage ve revision tabanlı live API; yalnızca izole workspace gerçek canlı değişim kullanıyor. Normal arayüzde eski yerel renk ve ikon cache'leri nedeniyle restart korunuyor.
- A03: Altı textual sensör slotu, single-flight/TTL/generation modeli. Sensör güvenlik kontrollerine cache bağlanmadı. İlk sorgu ve metinsel D-Bus miss henüz bloklayabilir; cihaz kimliği ve bütün tüketiciler açık.
- A07: `centurion --simulate` ayrı workspace, gerçek grafikler, altı fixture ve gerçek S10/S13 rapor parser'ları. Gerçek shell'i açmaz; firmware, helper, scene, restore ve daemon işlemleri çalıştırılmaz. Donanım emülasyonu tamamlanmış değildir.
- A08: Native Qt görsel test harness'i ve CI artifact yükleme adımı. Baseline verilirse karşılaştırılır; yoksa tekrar-render ve geometry smoke. Henüz Qt ile çalıştırılmadı, onaylı baseline yok.
- D04: Simulation bağlamında 18 TR katalog girdisi. İki statik palette testi, güvenli yeni storage ve palette lookup sözleşmesine uyarlanmıştır; yeni native test gerçek davranışı kontrol eder.

## Doğrulama

- 27/27 mevcut Python runner PASS, CO native simülasyonları: 454.710 per-core walks; 183.621 crash + 327.669 clean scenarios PASS.
- `telemetrycache_test.cpp` bağımsız C++20, `-Wall -Wextra -Wpedantic -Werror -pthread`, normal ve `-O2` derlemesi PASS; ASan/UBSan ile PASS. Bu test yalnızca cache algoritmasını doğrular.
- Türkçe katalog 5/5 PASS. Git diff --check ve ZIP bütünlük kontrolü PASS.
- `apt-get update`: Debian DNS çözümleme hatası; paket kurulumu "Unable to locate package". Debug ve Release CMake Qt6Config.cmake bulunamadı. Cargo/rustc bulunamadı. Qt GUI, visual regression ve Rust testleri çalıştırılamadı. Native GUI warning veya tam donanım güvenlik doğrulaması yapıldı denemez.
- Fiziksel donanım yazması, GitHub CI/push yapılmadı. Main/old/experimental değişmedi.
