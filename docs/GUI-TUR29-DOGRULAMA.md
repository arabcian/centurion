## Teknik ayrıntılar
- Build logu: `hometab.h:136` PresentationReading tanımı görünmüyor; `std::optional` complete type gerektiriyor. `sysinfo.h` doğrudan include. `last` hataları zincirleme. Bu hata PGO/LTO optimizasyonu kaynaklı değildir; native tekrar derleme gerekir.
- Scene readback sonucu ile active scene kimliği ayrı. Rutin başarı ve running olayları varsayılan görünümde gizlenir; Show all events bunları gösterir. Gerçek skip/error/refused/mismatch/missing listelenir; helper mismatch ayrıntısı sınırı belirtilir. Mevcut root write/rollback algoritması değiştirilmedi. 32 uyuşmazlığın gerçek kaynağı ekran görüntüsünden belirlenemez; yeni log teşhis için gerçek key ve mevcut örnek path/value verisini gösterir. Scene history sınırı 200 olay, detay 16KiB; kesilme ellipsis ile işaretlenir.
- NVIDIA metadata iki modülden keşfedilir. Kurulu modül bilgisi semantik güvenlik kanıtı değildir. Bilinen validator ve root dosya güvenliği korunur, yeni bool/scalar tipler range/syntax kontrolü ve GUI uyarısı ile yazılabilir. Tanınmayan string/array salt okunur. Kaydedilmiş ama artık keşfedilemeyen ayar varsa sessiz silme önlenir. Yeni helper ve GUI birlikte gerekir. Root yetkisinde PATH araması yok. Bilinmeyen stringlerin tam düzenleme desteği açık. Backup restore validation dynamic scalar ile genişletildi; Rust native kontrolü açık.
- Debugfs: mevcut root-owned `/run/centurion/debugfs.json` yöntemi. Read-only refresh debugfs mount etmez; root yazma yollarının önceki `ensure_debugfs` davranışı korunur. Kernelin sunmadığı dosya yok sayılır, present-but-unreadable null olarak ayrılır. Root snapshot bir describe boyunca bir kez okunur. MC/PKG için gerçek kernel topolojisi doğrulanmadı. Gerekirse `Scheduler (EEVDF)` export'u ile dosyalar belirlenebilir.
- Kernel export: mevcut `ksnap` allow/deny, no symlink, read-only, max 60k satır, toplam 12MiB raw, 4KiB değer ve 8s tarama bütçesi değişmedi; GUI JSON cevap limiti sadece health-reader/ksnap için 80MiB. Export tam alınmış snapshot, sınırsız /sys dump değil. Filtreler export'u etkilemez. Özel aygıt bilgileri içerebilir; paylaşmadan incele. Format makine okunur JSON, ekran görünümü tablo.
- Boot Options: `cpuidle.governor=menu`, `preempt=voluntary`, `noautogroup`, `page_alloc.shuffle=1`, `transparent_hugepage_shmem=advise/never`, `numa_balancing=disable/enable`, `pci=pcie_bus_perf`, `iommu.strict=1/0`, `log_buf_len=4M`, `printk.time=1`, `no_console_suspend`, `cpuhp.parallel=0`. Kernel belgeleri https://docs.kernel.org/admin-guide/kernel-parameters.html . Her seçenek opt-in; riskli seçeneklerde caution; mevcut boot guard korunur; hiçbir otomatik etkinleştirme yapılmadı.
